Bab 1.1

Instalasi

Langkah pertama dalam perjalananmu belajar Rust: menginstal Rust itu sendiri. Kita akan mengunduhnya lewat rustup, alat command line resmi untuk mengelola versi Rust. Kamu butuh koneksi internet untuk proses ini.

ℹ️ Kalau kamu tidak mau pakai rustup

Ada cara instalasi lain yang dijelaskan di halaman resmi Other Rust Installation Methods. Tapi untuk hampir semua orang, rustup adalah pilihan terbaik — dan itu yang akan kita pakai di kursus ini.

Langkah-langkah di halaman ini akan menginstal versi stabil terbaru dari compiler Rust. Rust punya jaminan stabilitas yang kuat: semua contoh kode di kursus ini yang berhasil dikompilasi hari ini akan tetap berhasil dikompilasi dengan versi Rust yang lebih baru nanti. Output di terminalmu mungkin sedikit berbeda (karena Rust terus memperbaiki pesan error), tapi secara fungsional semuanya akan tetap bekerja seperti yang dijelaskan di sini.

💡 Cara membaca perintah command line di kursus ini

Baris yang harus kamu ketik di terminal selalu diawali tanda $ (di Linux/macOS/PowerShell) atau > (di Windows CMD). Kamu tidak perlu mengetik tanda itu — itu hanya representasi prompt terminal. Baris yang tidak diawali tanda tersebut biasanya adalah output dari perintah sebelumnya.

Menginstal rustup di Linux atau macOS

Buka terminal, lalu ketik perintah berikut:

$ curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh

Perintah ini mengunduh sebuah script dan langsung menjalankan instalasi rustup, yang kemudian menginstal versi stabil terbaru Rust. Kamu mungkin akan diminta memasukkan password. Kalau instalasi berhasil, kamu akan melihat pesan berikut: 

Rust is installed now. Great!

Kamu juga akan butuh sebuah linker — program yang dipakai Rust untuk menggabungkan hasil kompilasi menjadi satu file executable. Kemungkinan besar linker sudah terpasang di sistemmu. Kalau muncul error terkait linker, install compiler C (biasanya sudah termasuk linker di dalamnya). Compiler C juga berguna karena beberapa package Rust yang populer bergantung pada kode C.

Di macOS, kamu bisa mendapatkan compiler C dengan menjalankan:

$ xcode-select --install

Di Linux, install GCC atau Clang sesuai dokumentasi distronya. Misalnya di Ubuntu, install package build-essential.

Menginstal rustup di Windows

Di Windows, buka rust-lang.org/tools/install dan ikuti instruksinya. Di suatu titik proses instalasi, kamu akan diminta menginstal Visual Studio — ini menyediakan linker dan native library yang dibutuhkan untuk mengompilasi program Rust di Windows.

Sisa perintah di kursus ini bisa dijalankan baik di cmd.exe maupun PowerShell. Kalau ada perbedaan penting, akan dijelaskan secara spesifik.

Memastikan Instalasi Berhasil

Buka terminal/shell baru dan ketik:

$ rustc --version

Kamu seharusnya melihat nomor versi, commit hash, dan tanggal commit, dengan format seperti ini:

rustc x.y.z (abcabcabc yyyy-mm-dd)

Kalau informasi ini muncul, selamat — Rust berhasil terinstal! Kalau tidak muncul, periksa apakah Rust sudah masuk ke variabel sistem PATH:

  • Windows CMD: echo %PATH%
  • PowerShell: echo $env:Path
  • Linux/macOS: echo $PATH

Kalau semua sudah benar tapi Rust masih belum terdeteksi, kamu bisa minta bantuan di halaman komunitas Rust — di sana kamu akan bertemu sesama "Rustacean" (julukan iseng untuk programmer Rust).

Update dan Uninstall

Setelah Rust terinstal lewat rustup, meng-update ke versi terbaru sangat mudah:

$ rustup update

Untuk uninstall Rust dan rustup:

$ rustup self uninstall

Membaca Dokumentasi Lokal

Instalasi Rust juga menyertakan salinan lokal dari dokumentasi resminya, supaya kamu bisa membacanya secara offline. Jalankan rustup doc untuk membuka dokumentasi lokal itu di browser.

💡 Kebiasaan baik sejak awal

Kapan pun kamu menemukan tipe atau fungsi dari standard library dan tidak yakin cara pakainya, buka dokumentasi API-nya. Ini kebiasaan yang akan sering kamu pakai sepanjang karier Rust-mu.

Text Editor dan IDE

Kursus ini tidak mengasumsikan tools tertentu untuk menulis kode. Hampir semua text editor bisa dipakai! Tapi banyak editor dan IDE punya dukungan bawaan untuk Rust lewat rust-analyzer, yang memberi fitur seperti auto-complete dan deteksi error langsung saat mengetik. Daftar editor yang didukung bisa dilihat di halaman tools Rust.

Bekerja Offline dengan Kursus Ini

Di beberapa contoh nanti, kita akan memakai package Rust di luar standard library. Untuk mengerjakannya kamu butuh koneksi internet, atau bisa mengunduh dependency-nya lebih dulu supaya bisa dipakai offline nanti (istilah cargo dan perintah-perintah di bawah akan dijelaskan lebih detail di subbab berikutnya): 

$ cargo new get-dependencies
$ cd get-dependencies
$ cargo add rand@0.10.1 trpl@0.2.0

Perintah ini akan meng-cache package tersebut supaya tidak perlu diunduh ulang nanti. Setelah dijalankan, folder get-dependencies boleh dihapus. Selanjutnya kamu bisa memakai flag --offline pada semua perintah cargo agar memakai cache ini alih-alih mencoba mengakses internet.

Kenapa Rust butuh sebuah "linker" untuk mengompilasi program?

Ringkasan

  • Rust diinstal lewat rustup, alat resmi pengelola versi Rust.
  • Rust butuh linker (biasanya sudah ada, atau ikut terpasang bersama compiler C).
  • Cek instalasi dengan rustc --version.
  • rustup update untuk update, rustup self uninstall untuk uninstall.
  • rustup doc membuka dokumentasi resmi secara offline di browser.
