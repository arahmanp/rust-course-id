Bab 1.2

Hello, World!

Sekarang Rust sudah terinstal, saatnya menulis program Rust pertamamu. Sudah jadi tradisi ketika belajar bahasa baru untuk menulis program kecil yang menampilkan teks Hello, world! ke layar — jadi mari kita lakukan hal yang sama.

ℹ️ Familiar dengan command line?

Kursus ini mengasumsikan kamu setidaknya cukup familiar dengan command line. Rust sendiri tidak menuntut editor atau tooling tertentu — kalau kamu lebih suka pakai IDE daripada command line murni, silakan. Banyak IDE modern sudah punya dukungan Rust yang baik lewat rust-analyzer.

Menyiapkan Folder Proyek

Buat folder untuk menyimpan kode Rust-mu. Rust tidak peduli di mana kodemu berada, tapi untuk latihan di kursus ini, kita sarankan membuat folder projects di home directory-mu dan menyimpan semua proyek di sana.

Buka terminal dan jalankan (Linux, macOS, atau PowerShell di Windows):

$ mkdir ~/projects
$ cd ~/projects
$ mkdir hello_world
$ cd hello_world

Kalau kamu pakai Windows CMD:

> mkdir "%USERPROFILE%\projects"
> cd /d "%USERPROFILE%\projects"
> mkdir hello_world
> cd hello_world

Menulis dan Menjalankan Program Rust

Buat file baru bernama main.rs. File Rust selalu berakhiran .rs. Kalau nama filemu terdiri lebih dari satu kata, konvensinya memakai underscore, misalnya hello_world.rs, bukan helloworld.rs.

Buka main.rs dan tulis kode berikut:

Nama berkas: main.rs

fn main() {
    println!("Hello, world!");
}

Simpan file itu, lalu kembali ke terminal di folder ~/projects/hello_world. Di Linux atau macOS, kompilasi dan jalankan filenya dengan: 

$ rustc main.rs
$ ./main
Hello, world!

Di Windows, jalankan .\main alih-alih ./main:

> rustc main.rs
> .\main
Hello, world!

Apa pun sistem operasimu, teks Hello, world! seharusnya muncul di terminal. Kalau tidak muncul, kembali ke bagian "Memastikan Instalasi Berhasil" di subbab sebelumnya.

Kalau Hello, world! berhasil muncul — selamat! Kamu baru saja resmi menulis program Rust pertamamu. Itu artinya kamu sekarang seorang programmer Rust. Selamat datang! 🎉

Anatomi Sebuah Program Rust

Mari kita bedah program "Hello, world!" ini baris demi baris. Bagian pertama:

fn main() {

}

Baris ini mendefinisikan sebuah fungsi bernama main. Fungsi main itu istimewa: fungsi ini selalu menjadi kode pertama yang dijalankan di setiap program Rust yang bisa dieksekusi. Di sini, baris pertama mendeklarasikan fungsi main tanpa parameter dan tidak mengembalikan apa pun. Kalau ada parameter, mereka akan diletakkan di dalam tanda kurung ().

Badan fungsi dibungkus dengan {}. Rust mewajibkan kurung kurawal di sekitar seluruh badan fungsi. Kebiasaan gaya penulisan yang baik: letakkan kurung kurawal pembuka di baris yang sama dengan deklarasi fungsi, dengan satu spasi di antaranya.

💡 rustfmt: biar kode selalu rapi

Kalau kamu ingin gaya penulisan kode yang konsisten di semua proyek Rust, kamu bisa memakai rustfmt — alat formatter otomatis bawaan Rust. Sudah terinstal otomatis bersama Rust, jadi kamu tinggal memakainya.

Badan fungsi main berisi kode berikut:

println!("Hello, world!");

Baris inilah yang melakukan seluruh pekerjaan program kecil ini: ia mencetak teks ke layar. Ada tiga detail penting yang perlu diperhatikan:

  1. println! memanggil sebuah macro Rust. Kalau ia memanggil fungsi biasa, penulisannya akan menjadi println (tanpa tanda seru). Macro adalah cara menulis kode yang menghasilkan kode lain untuk memperluas sintaks Rust — akan dibahas mendalam di Bab 20. Untuk sekarang, cukup ingat: tanda ! berarti kamu memanggil macro, bukan fungsi biasa, dan macro tidak selalu mengikuti aturan yang sama seperti fungsi.
  2. String "Hello, world!" — kita mengoper string ini sebagai argumen ke println!, dan string itulah yang dicetak ke layar.
  3. Titik koma ; di akhir baris menandakan bahwa ekspresi ini selesai dan ekspresi berikutnya siap dimulai. Sebagian besar baris kode Rust diakhiri titik koma.

Kompilasi dan Eksekusi Adalah Dua Langkah Terpisah

Kamu baru saja menjalankan program yang baru dibuat, jadi mari kita telaah tiap langkahnya.

Sebelum dijalankan, program Rust harus dikompilasi lebih dulu memakai compiler Rust, dengan memanggil perintah rustc dan memberi nama file sumbernya: 

$ rustc main.rs

Kalau kamu berlatar belakang C atau C++, ini mirip gcc atau clang. Setelah berhasil dikompilasi, Rust menghasilkan sebuah file binary yang bisa dieksekusi.

Di Linux, macOS, dan PowerShell Windows, kamu bisa melihat file executable-nya dengan ls:

$ ls
main  main.rs

Dengan CMD di Windows, hasilnya sedikit berbeda:

> dir /B
main.exe
main.pdb
main.rs

Terlihat file source code (.rs), file executable (main.exe di Windows, atau main di sistem lain), dan — khusus Windows — satu file berisi informasi debugging berekstensi .pdb. Dari sini kamu tinggal menjalankan file main atau main.exe tersebut.

ℹ️ Kalau kamu terbiasa dengan bahasa dinamis

Kalau kamu lebih familiar dengan bahasa seperti Ruby, Python, atau JavaScript, kamu mungkin belum terbiasa mengompilasi dan menjalankan program sebagai dua langkah terpisah. Rust adalah bahasa ahead-of-time compiled: kamu bisa mengompilasi sebuah program lalu memberikan file executable-nya ke orang lain, dan mereka bisa menjalankannya tanpa perlu menginstal Rust sama sekali. Kalau kamu memberi orang lain file .rb, .py, atau .js, mereka tetap butuh Ruby, Python, atau JavaScript terpasang di sistem mereka. Setiap desain bahasa selalu punya trade-off masing-masing.

Memakai rustc langsung sudah cukup untuk program sederhana, tapi begitu proyekmu bertambah besar, kamu akan butuh cara mengelola opsi kompilasi dan membagikan kodemu dengan lebih mudah. Selanjutnya kita akan berkenalan dengan Cargo — tool yang akan membantumu menulis program Rust dunia nyata.

Apa yang membedakan pemanggilan macro dari pemanggilan fungsi biasa di Rust?

Ringkasan

  • Fungsi main selalu jadi titik masuk pertama program Rust.
  • println! adalah macro (ditandai !), bukan fungsi biasa.
  • Sebagian besar baris kode Rust diakhiri titik koma ;.
  • rustc namafile.rs mengompilasi kode menjadi file executable terpisah — kompilasi dan eksekusi adalah dua langkah yang berbeda.
  • Rust adalah bahasa ahead-of-time compiled: hasil kompilasinya bisa dijalankan tanpa Rust terpasang.
