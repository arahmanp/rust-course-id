Bab 3.5

Alur Kontrol

Kemampuan menjalankan kode tergantung apakah sebuah kondisi true, dan kemampuan menjalankan kode berulang kali selama sebuah kondisi true, adalah komponen dasar di hampir semua bahasa pemrograman. Konstruksi paling umum untuk mengontrol alur eksekusi kode Rust adalah ekspresi if dan loop.

Ekspresi if

Ekspresi if memungkinkanmu bercabang kode tergantung kondisi. Kamu memberikan sebuah kondisi lalu menyatakan, "Kalau kondisi ini terpenuhi, jalankan blok kode ini. Kalau tidak terpenuhi, jangan jalankan blok kode ini."

Buat proyek baru bernama branches untuk mengeksplorasi ekspresi if. Di src/main.rs, tulis:

Nama berkas: src/main.rs

fn main() {
    let number = 3;

    if number < 5 {
        println!("kondisinya benar");
    } else {
        println!("kondisinya salah");
    }
}

Semua ekspresi if diawali keyword if, diikuti sebuah kondisi. Di sini, kondisinya memeriksa apakah variabel number bernilai kurang dari 5. Kita letakkan blok kode yang dijalankan kalau kondisinya true langsung setelah kondisi tersebut, di dalam kurung kurawal. Blok kode yang berasosiasi dengan kondisi di ekspresi if kadang disebut arm, sama seperti arm di ekspresi match yang kita bahas di Bab 2.

Secara opsional, kita juga bisa menyertakan ekspresi else — seperti di contoh ini — untuk memberi program sebuah blok kode alternatif yang dijalankan kalau kondisinya false. Kalau kamu tidak menyediakan ekspresi else dan kondisinya false, program hanya akan melewati blok if dan lanjut ke kode berikutnya.

Coba jalankan kode ini; kamu seharusnya melihat output:

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.31s
     Running `target/debug/branches`
kondisinya benar

Mari coba ubah nilai number menjadi nilai yang membuat kondisinya false:

let number = 7;

Jalankan lagi programnya, dan lihat hasilnya:

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.31s
     Running `target/debug/branches`
kondisinya salah

Perlu dicatat juga: kondisi di kode ini harus bertipe bool. Kalau kondisinya bukan bool, kita akan mendapat error. Misalnya, coba jalankan kode berikut:

❌ Belum bisa dikompilasi

Nama berkas: src/main.rs

fn main() {
    let number = 3;

    if number {
        println!("number bernilai three");
    }
}

Kondisi if ini bernilai 3, dan Rust melempar error:

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
error[E0308]: mismatched types
 --> src/main.rs:4:8
  |
4 |     if number {
  |        ^^^^^^ expected `bool`, found integer

For more information about this error, try `rustc --explain E0308`.
error: could not compile `branches` (bin "branches") due to 1 previous error

Error ini menandakan Rust mengharapkan bool tapi mendapat integer. Berbeda dari bahasa seperti Ruby dan JavaScript, Rust tidak akan otomatis mencoba mengonversi tipe non-Boolean menjadi Boolean. Kamu harus eksplisit dan selalu memberi if sebuah Boolean sebagai kondisinya. Kalau kita ingin blok kode if hanya berjalan ketika sebuah angka tidak sama dengan 0, misalnya, kita bisa mengubah ekspresi if-nya menjadi:

Nama berkas: src/main.rs

fn main() {
    let number = 3;

    if number != 0 {
        println!("number bernilai selain nol");
    }
}

Menjalankan kode ini akan mencetak number bernilai selain nol.

Menangani Banyak Kondisi dengan else if

Kamu bisa memakai banyak kondisi dengan menggabungkan if dan else dalam ekspresi else if. Contoh:

Nama berkas: src/main.rs

fn main() {
    let number = 6;

    if number % 4 == 0 {
        println!("number habis dibagi 4");
    } else if number % 3 == 0 {
        println!("number habis dibagi 3");
    } else if number % 2 == 0 {
        println!("number habis dibagi 2");
    } else {
        println!("number tidak habis dibagi 4, 3, atau 2");
    }
}

Program ini punya empat kemungkinan jalur. Setelah dijalankan, kamu akan melihat output:

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.31s
     Running `target/debug/branches`
number habis dibagi 3

Saat program ini dijalankan, ia memeriksa setiap ekspresi if secara berurutan dan menjalankan badan pertama yang kondisinya bernilai true. Perhatikan walaupun 6 juga habis dibagi 2, kita tidak melihat output number habis dibagi 2, atau teks dari blok else. Itu karena Rust hanya menjalankan blok untuk kondisi true pertama, dan begitu ditemukan, ia bahkan tidak lagi memeriksa yang lain.

Memakai terlalu banyak ekspresi else if bisa membuat kodemu berantakan, jadi kalau kamu punya lebih dari satu, kamu mungkin ingin merefactor kodenya. Bab 6 menjelaskan konstruksi percabangan Rust yang lebih kuat bernama match untuk kasus-kasus seperti ini.

Memakai if dalam Statement let

Karena if adalah ekspresi, kita bisa memakainya di sisi kanan sebuah statement let untuk mengikat hasilnya ke sebuah variabel:

Nama berkas: src/main.rs

fn main() {
    let condition = true;
    let number = if condition { 5 } else { 6 };

    println!("Nilai number adalah: {number}");
}

Variabel number akan terikat ke sebuah nilai berdasarkan hasil ekspresi if. Jalankan kode ini untuk melihat apa yang terjadi: 

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.30s
     Running `target/debug/branches`
Nilai number adalah: 5

Ingat, blok kode dievaluasi menjadi ekspresi terakhir di dalamnya, dan angka begitu saja juga ekspresi. Dalam kasus ini, nilai dari seluruh ekspresi if bergantung pada blok kode mana yang dijalankan. Ini berarti nilai yang berpotensi menjadi hasil dari setiap arm if harus bertipe sama; di contoh sebelumnya, hasil arm if maupun arm else sama-sama integer i32. Kalau tipenya tidak cocok, seperti contoh berikut, kita akan mendapat error:

❌ Belum bisa dikompilasi

Nama berkas: src/main.rs

fn main() {
    let condition = true;

    let number = if condition { 5 } else { "six" };

    println!("Nilai number adalah: {number}");
}

Ketika kita coba kompilasi kode ini, kita akan dapat error. Arm if dan else punya tipe nilai yang tidak kompatibel, dan Rust menunjukkan persis di mana masalahnya: 

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
error[E0308]: `if` and `else` have incompatible types
 --> src/main.rs:4:44
  |
4 |     let number = if condition { 5 } else { "six" };
  |                                 -          ^^^^^ expected integer, found `&str`
  |                                 |
  |                                 expected because of this

For more information about this error, try `rustc --explain E0308`.
error: could not compile `branches` (bin "branches") due to 1 previous error

Ekspresi di blok if dievaluasi menjadi integer, dan ekspresi di blok else dievaluasi menjadi string. Ini tidak akan bekerja, karena variabel harus punya satu tipe tunggal, dan Rust perlu tahu secara pasti saat compile-time tipe apa yang dimiliki variabel number. Mengetahui tipe number memungkinkan compiler memverifikasi tipenya valid di setiap tempat kita memakai number. Rust tidak akan bisa melakukan itu kalau tipe number baru ditentukan saat runtime — compiler-nya akan jadi lebih kompleks dan memberi lebih sedikit jaminan tentang kode itu kalau ia harus melacak banyak kemungkinan tipe hipotetis untuk variabel apa pun.

Kenapa kode let number = if condition { 5 } else { "six" }; gagal dikompilasi?

Pengulangan dengan Loop

Sering kali berguna untuk menjalankan sebuah blok kode lebih dari sekali. Untuk tugas ini, Rust menyediakan beberapa loop, yang akan menjalankan kode di dalam badan loop sampai akhir lalu langsung kembali ke awal. Untuk bereksperimen dengan loop, mari buat proyek baru bernama loops.

Rust punya tiga jenis loop: loop, while, dan for. Mari coba masing-masing.

Mengulang Kode dengan loop

Keyword loop memberi tahu Rust untuk menjalankan sebuah blok kode berulang kali, entah selamanya atau sampai kamu secara eksplisit memberi tahu untuk berhenti.

Sebagai contoh, ubah src/main.rs di folder loops-mu menjadi:

Nama berkas: src/main.rs

fn main() {
    loop {
        println!("lagi!");
    }
}

Ketika kita jalankan program ini, kita akan melihat lagi! dicetak berulang-ulang terus menerus sampai kita menghentikan programnya secara manual. Kebanyakan terminal mendukung pintasan keyboard ctrl-c untuk menginterupsi program yang terjebak dalam loop tanpa henti. Coba jalankan: 

$ cargo run
   Compiling loops v0.1.0 (file:///projects/loops)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.08s
     Running `target/debug/loops`
lagi!
lagi!
lagi!
lagi!
^Clagi!

Simbol ^C merepresentasikan titik kamu menekan ctrl-c. Kamu mungkin melihat atau tidak melihat kata lagi! tercetak setelah ^C, tergantung posisi kode saat menerima sinyal interupsi.

Untungnya, Rust juga menyediakan cara keluar dari loop lewat kode. Kamu bisa menaruh keyword break di dalam loop untuk memberi tahu program kapan berhenti menjalankan loop itu. Ingat kita sudah melakukan ini di permainan tebak angka Bab 2 untuk keluar dari program saat pengguna menang dengan menebak angka yang benar.

Kita juga memakai continue di permainan tebak angka, yang dalam sebuah loop memberi tahu program untuk melewati sisa kode di iterasi ini dan lanjut ke iterasi berikutnya.

Mengembalikan Nilai dari Loop

Salah satu kegunaan loop adalah mencoba ulang sebuah operasi yang kamu tahu mungkin gagal, seperti memeriksa apakah sebuah thread sudah menyelesaikan pekerjaannya. Kamu mungkin juga perlu mengoper hasil operasi itu ke luar loop, ke bagian kode lainnya. Untuk melakukan ini, kamu bisa menambahkan nilai yang ingin dikembalikan setelah ekspresi break yang kamu pakai untuk menghentikan loop; nilai itu akan dikembalikan dari loop supaya bisa kamu pakai, seperti ini: 

fn main() {
    let mut counter = 0;

    let result = loop {
        counter += 1;

        if counter == 10 {
            break counter * 2;
        }
    };

    println!("Hasilnya adalah {result}");
}

Sebelum loop, kita mendeklarasikan variabel bernama counter dan menginisialisasinya ke 0. Lalu, kita mendeklarasikan variabel bernama result untuk menampung nilai yang dikembalikan dari loop. Di setiap iterasi loop, kita menambah 1 ke variabel counter, lalu memeriksa apakah counter sama dengan 10. Kalau ya, kita pakai keyword break dengan nilai counter * 2. Setelah loop, kita pakai titik koma untuk mengakhiri statement yang menetapkan nilai ke result. Terakhir, kita mencetak nilai di result, yang dalam kasus ini adalah 20.

Kamu juga bisa return dari dalam loop. Sementara break hanya keluar dari loop saat ini, return selalu keluar dari seluruh fungsi.

Membedakan Antar Loop dengan Label

Kalau kamu punya loop di dalam loop, break dan continue berlaku untuk loop paling dalam di titik itu. Kamu bisa secara opsional menentukan loop label pada sebuah loop, lalu memakainya bersama break atau continue untuk menentukan bahwa keyword itu berlaku untuk loop yang diberi label, bukan loop paling dalam. Loop label harus diawali tanda kutip tunggal. Berikut contoh dengan dua loop bersarang: 

fn main() {
    let mut count = 0;
    'counting_up: loop {
        println!("count = {count}");
        let mut remaining = 10;

        loop {
            println!("remaining = {remaining}");
            if remaining == 9 {
                break;
            }
            if count == 2 {
                break 'counting_up;
            }
            remaining -= 1;
        }

        count += 1;
    }
    println!("End count = {count}");
}

Loop luar diberi label 'counting_up, dan akan menghitung naik dari 0 sampai 2. Loop dalam, tanpa label, menghitung turun dari 10 ke 9. break pertama yang tidak menentukan label hanya akan keluar dari loop dalam. Statement break 'counting_up; akan keluar dari loop luar. Kode ini mencetak: 

count = 0
remaining = 10
remaining = 9
count = 1
remaining = 10
remaining = 9
count = 2
remaining = 10
End count = 2

Loop Kondisional dengan while

Program sering kali perlu mengevaluasi sebuah kondisi di dalam loop. Selama kondisinya true, loop-nya berjalan. Ketika kondisinya sudah tidak true lagi, program memanggil break, menghentikan loop-nya. Perilaku seperti ini bisa diimplementasikan dengan kombinasi loop, if, else, dan break — kamu boleh coba sekarang kalau mau. Tapi pola ini begitu umum sehingga Rust punya konstruksi bahasa bawaan untuknya, disebut loop while. Berikut kita pakai while untuk mengulang program tiga kali, menghitung mundur setiap kali, lalu setelah loop-nya, mencetak sebuah pesan dan keluar:

Nama berkas: src/main.rs

fn main() {
    let mut number = 3;

    while number != 0 {
        println!("{number}!");

        number -= 1;
    }

    println!("LUNCUR!!!");
}

Konstruksi ini menghilangkan banyak nesting yang akan dibutuhkan kalau kamu memakai loop, if, else, dan break, dan jauh lebih jelas. Selama sebuah kondisi bernilai true, kodenya berjalan; kalau tidak, loop-nya keluar.

Melakukan Perulangan Lewat Koleksi dengan for

Kamu bisa memilih memakai konstruksi while untuk melakukan perulangan pada elemen-elemen sebuah koleksi, seperti array. Misalnya, loop berikut mencetak setiap elemen di array a.

Nama berkas: src/main.rs

fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("nilainya adalah: {}", a[index]);

        index += 1;
    }
}

Di sini, kode menghitung naik lewat elemen-elemen dalam array. Ia mulai dari indeks 0, lalu melakukan loop sampai mencapai indeks terakhir dalam array (yaitu, ketika index < 5 sudah tidak true lagi). Menjalankan kode ini akan mencetak setiap elemen dalam array: 

$ cargo run
   Compiling loops v0.1.0 (file:///projects/loops)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.32s
     Running `target/debug/loops`
nilainya adalah: 10
nilainya adalah: 20
nilainya adalah: 30
nilainya adalah: 40
nilainya adalah: 50

Kelima nilai array muncul di terminal, sesuai harapan. Walaupun index akan mencapai nilai 5 di suatu titik, loop-nya berhenti dijalankan sebelum mencoba mengambil elemen keenam dari array.

Tapi, pendekatan ini rawan error — kita bisa membuat program panic kalau nilai index atau kondisi ujinya salah. Misalnya, kalau kamu mengubah definisi array a menjadi punya empat elemen, tapi lupa mengubah kondisinya menjadi while index < 4, kodenya akan panic. Ini juga lambat, karena compiler menambahkan kode runtime untuk melakukan pengecekan kondisional apakah indeksnya masih dalam batas array di setiap iterasi loop.

Sebagai alternatif yang lebih ringkas, kamu bisa memakai loop for dan menjalankan sebuah kode untuk setiap item dalam koleksi. Loop for terlihat seperti kode berikut.

Nama berkas: src/main.rs

fn main() {
    let a = [10, 20, 30, 40, 50];

    for element in a {
        println!("nilainya adalah: {element}");
    }
}

Ketika kita jalankan kode ini, kita akan melihat output yang sama seperti sebelumnya. Yang lebih penting, kita sekarang meningkatkan keamanan kode dan menghilangkan kemungkinan bug yang bisa terjadi akibat melewati ujung array atau tidak sampai jauh dan melewatkan beberapa item. Kode mesin yang dihasilkan dari loop for juga bisa lebih efisien, karena indeksnya tidak perlu dibandingkan dengan panjang array di setiap iterasi.

Memakai loop for, kamu tidak perlu ingat mengubah kode lain kalau kamu mengubah jumlah nilai dalam array, seperti yang harus kamu lakukan dengan metode di contoh while sebelumnya.

Keamanan dan keringkasan loop for membuatnya menjadi konstruksi loop yang paling umum dipakai di Rust. Bahkan dalam situasi di mana kamu ingin menjalankan kode sejumlah kali tertentu, seperti contoh hitung mundur yang memakai loop while sebelumnya, kebanyakan Rustacean akan memakai loop for. Caranya adalah memakai Range, disediakan oleh standard library, yang menghasilkan semua angka berurutan mulai dari satu angka sampai sebelum angka lainnya.

Begini tampilan hitung mundur memakai loop for dan method lain yang belum kita bahas, rev, untuk membalik urutan range-nya:

Nama berkas: src/main.rs

fn main() {
    for number in (1..4).rev() {
        println!("{number}!");
    }
    println!("LUNCUR!!!");
}

Kode ini sedikit lebih bagus, bukan?

🏋️ Coba Sendiri

Kamu berhasil menyelesaikan bab ini! Ini bab yang cukup besar — kamu belajar tentang variabel, tipe data scalar dan compound, fungsi, komentar, ekspresi if, dan loop. Untuk berlatih dengan konsep-konsep yang dibahas di bab ini, coba bangun program untuk:

  • Mengonversi suhu antara Fahrenheit dan Celsius.
  • Menghasilkan bilangan Fibonacci ke-n.
  • Mencetak lirik lagu Natal "The Twelve Days of Christmas", memanfaatkan pengulangan di lagunya.

Ringkasan Bab 3

  • Variabel immutable secara default (mut untuk mengubahnya), konstanta selalu immutable, dan shadowing membuat variabel baru dengan nama sama.
  • Tipe scalar (integer, float, bool, char) dan tipe compound (tuple, array) adalah fondasi sistem tipe Rust.
  • Fungsi memakai snake_case, parameter wajib beranotasi tipe, dan nilai kembaliannya adalah ekspresi terakhir (tanpa titik koma) di badannya.
  • if adalah ekspresi (bisa dipakai di let), kondisinya wajib bool.
  • Tiga jenis loop: loop (tanpa henti, bisa mengembalikan nilai lewat break nilai), while (kondisional), dan for (paling umum, aman, dan ringkas untuk koleksi/range).

Ketika kamu siap lanjut, kita akan bahas sebuah konsep di Rust yang tidak lazim ada di bahasa pemrograman lain: ownership.
